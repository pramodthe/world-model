# World Models

My notes, paper summaries, and experiments while learning about world models: neural networks that learn how an environment works so an agent can predict, imagine, and plan.

## Structure

| Folder | What goes there |
|---|---|
| `notes/` | Concept notes, one file per topic |
| `papers/` | Paper summaries |
| `experiments/` | Code I write to try things out |

## Learning path

- [ ] What a world model is (observation, latent state, dynamics, reward)
- [ ] World Models — Ha & Schmidhuber (2018): VAE + MDN-RNN + controller
- [ ] PlaNet (2019): planning in latent space
- [ ] Dreamer v1–v3: learning behavior inside imagined rollouts
- [ ] MuZero: planning with a learned model
- [ ] JEPA / V-JEPA: predicting in representation space
- [ ] Video world models (Genie, Sora-style simulators)
- [ ] Build a small world model for a simple environment (e.g. CartPole or CarRacing)
